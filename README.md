# 오퀴즈 — 5문제 챌린지

GitHub Pages에서 제공하는 공유용 프런트엔드입니다.

- `index.html`: 웹에서 실행
- `oquiz.html`: 다운로드 후 브라우저에서 실행하는 단일 HTML
- 퀴즈는 공개 API 게이트웨이와 Dify Workflow를 통해 Open Trivia DB에서 가져옵니다.
- 인터넷 연결이 필요하며 로그인·설치·API 키 입력은 필요하지 않습니다.
- 화면 안내는 한국어, 문제·보기는 영어 원문입니다.
- API 키와 서버 비밀값은 이 저장소에 포함되지 않습니다.

문제 출처: [Open Trivia DB](https://opentdb.com/), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
